# Web Profile & Information System - Ponpes Darul Ulum Tlasih

![Framework](https://img.shields.io/badge/Framework-CodeIgniter--4-firebrick)
![Developer](https://img.shields.io/badge/Developer-DigitalNote%20by%20Rofian-blue)

Sistem informasi berbasis web resmi untuk **Pondok Pesantren Darul Ulum Tlasih, Tulangan**. Proyek ini dikembangkan oleh **DigitalNote by Rofian** sebagai upaya digitalisasi institusi pendidikan Islam untuk mempermudah akses informasi publik dan manajemen internal santri.

## 📌 Tentang Proyek
Aplikasi ini dirancang untuk menjadi pusat informasi digital bagi wali santri dan masyarakat luas. Menggunakan framework **CodeIgniter 4**, sistem ini menawarkan performa yang ringan, cepat, dan aman. Proyek ini mencakup digitalisasi profil lembaga, kegiatan akademik, hingga pengelolaan database santri.

### ✨ Fitur Utama
*   **Digitalisasi Profil:** Informasi lengkap mengenai visi, misi, dan program pesantren.
*   **Manajemen Santri:** Sistem pengelolaan data santri yang terintegrasi dan terstruktur.
*   **Keamanan Terjamin:** Implementasi struktur folder `public/` sebagai akses utama untuk melindungi core sistem.
*   **Responsif:** Tampilan yang optimal diakses melalui perangkat mobile maupun desktop.

## 🛠️ Tech Stack
*   **Framework:** [CodeIgniter 4](https://codeigniter.com).
*   **Bahasa Pemrograman:** PHP 7.4+.
*   **Database:** MySQL.
*   **Pengembang:** DigitalNote by Rofian.
